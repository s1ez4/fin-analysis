# Анализ бухгалтерской отчетности

MVP для задания по дисциплине «Финансовый учет и анализ» (КНИТУ). Сайт без сборки на чистом JavaScript: принимает баланс (форма 0710001) и отчет о финансовых результатах (0710002) за 2–5 лет и считает таблицы анализа 2.2–2.11, строит графики, пишет шаблонные выводы и собирает отчет в Word и Excel.

**Сайт:** https://s1ez4.github.io/fin-analysis/ (пример «Россети Северный Кавказ» сразу: https://s1ez4.github.io/fin-analysis/?ex=rsk)

Примеры внутри (кнопки в разделе 1):
- ПАО «Нижнекамскнефтехим» (ИНН 1651000010) за 2023–2025 гг.;
- ПАО «Россети Северный Кавказ» (ИНН 2632082033) за 2023–2025 гг. — по годовой отчетности за 2025 г. с аудиторским заключением; у компании убытки и отрицательный собственный капитал, выводы и коэффициенты это учитывают (задолженность и маневренность при СК < 0 не сравниваются с нормативом).

Контрольные цифры НКНХ: баланс на 31.12.2025 — 615 400 445 тыс. руб.; чистая прибыль за 2023/2024/2025 — 22 566 606 / 31 761 201 / 19 008 798 тыс. руб. РСК: баланс на 31.12.2025 — 37 162 513 тыс. руб.; чистый убыток за 2023/2024/2025 — 11 837 008 / 17 093 201 / 12 766 890 тыс. руб.

## Что умеет

- **Ввод данных** по кодам строк, итоги считаются сами, проверка «актив = пассив», вставка столбцов из Excel, шаблон Excel и загрузка из него. Данные сохраняются в браузере (localStorage).
- **Таблицы анализа**: 2.2/2.3 горизонтальный, 2.4/2.5 вертикальный анализ, 2.6 ДЗ/КЗ, 2.7 формирование прибыли, 2.8 ликвидность, 2.9 финансовая устойчивость, 2.10 СОК/СДИ/ОИ и тип устойчивости, 2.11 группировка А1–А4/П1–П4.
- **Вкладка «Анализ финансовых результатов»** (переключатель вверху): таблица 1 — динамика и структура ФР (отклонения, темп роста, доля в выручке), таблица 2 — проверка цепочки ВП → Пп → Пнобл → ПЧ с колонкой «расхождение», таблица 3 — факторный анализ прибыли от продаж с проверкой «итог = Пп₁ − Пп₀», таблица 4 — 8 показателей рентабельности (ROE, ROA, оборотных и внеоборотных активов — по средним величинам), таблица 5 — факторы изменения чистой прибыли, таблицы 6–7 — модель Дюпона и разложение ΔROE цепными подстановками (везде строка проверки = 0), рисунки выручки/прибыли и рентабельности, автоматические выводы и резервы роста прибыли, выгрузка в Excel (каждая таблица на своем листе, лист «Графики» с данными и картинками рисунков, лист «Выводы»). Пустые строки считаются нулями (с пометкой), расходы со знаком «−» приводятся к положительным.
- **Графики** (Chart.js) расставлены как в образце: рис. 2.2–2.3 — динамика структуры актива и пассива, 2.4–2.5 — доля активов и пассивов, затем выручка и прибыль (можно выключить галочкой, тогда номера совпадут с образцом), ликвидность и финансовая устойчивость.
- **Шаблонные выводы без ИИ** под каждой таблицей и каждым рисунком: кнопка «Сгенерировать вывод» и «Заполнить пустые выводы шаблоном» сразу для всех.
- **Расчеты** с подстановкой в обозначениях образца, например
  `К₂₀₂₅ = 276493513 / 615400445 = 0,45 (ниже рекомендуемого значения 0,5)`.
- **Экспорт в Word — как в образце «ФУиА задание 1.doc»**: таблицы с теми же шапками, кеглем (8/10/11/12 пт), ширинами колонок и начертанием строк («Итого» — жирный курсив), числа без пробелов между разрядами; порядок: вводная фраза → расчеты (перед 2.8–2.10) → таблица → вывод → рисунок → вывод по рисунку; поля 3/1/2/2 см. Excel — те же таблицы, каждая на своем листе.
- Распознавание PDF и черновики выводов от Claude работают, только когда страница открыта внутри Claude. Локально эти кнопки неактивны — это нормально.

## Как запустить

Нужен только браузер. Можно просто открыть `index.html` двойным щелчком, но надежнее через локальный сервер:

```bash
py -m http.server 8000
```

(на Windows команда `python` часто открывает Microsoft Store — используйте `py`; на macOS/Linux — `python3 -m http.server 8000`)

Потом откройте http://localhost:8000 в браузере.

Для графиков и выгрузки в Excel/Word нужен интернет: библиотеки Chart.js, SheetJS и JSZip грузятся с cdnjs. Без интернета таблицы и выводы работают, а Word соберется без рисунков.

## Структура

```
index.html          разметка страницы
styles.css          оформление
js/data.js          справочник строк отчетности, пример НКНХ, хранение состояния
js/calc.js          расчеты: base(), коэффициенты LIQ/FIN, тип устойчивости, проверка нормативов, модель таблиц
js/charts.js        графики Chart.js на странице и PNG-картинки для Word
js/conclusions.js   правила шаблонных выводов
js/formulas.js      расчеты коэффициентов с подстановкой
js/docstyle.js      таблицы для Word и Excel в оформлении образца
js/export.js        выгрузка в Excel и Word
js/finres.js        вкладка «Анализ финансовых результатов»: таблицы 1–4, выводы, выгрузка в Excel
js/app.js           интерфейс: ввод, рендер, импорт, распознавание через Claude
```

## Как бесплатно выложить на GitHub Pages

1. Зарегистрируйтесь на https://github.com и создайте новый **публичный** репозиторий (кнопка **New**), например `fin-analysis`. Галочки «Add README» не ставьте.
2. В папке проекта выполните (подставьте свой логин):

   ```bash
   git remote add origin https://github.com/ЛОГИН/fin-analysis.git
   ```

   ```bash
   git branch -M main
   ```

   ```bash
   git push -u origin main
   ```

3. В репозитории на GitHub откройте **Settings → Pages**. В разделе **Build and deployment** выберите *Source: Deploy from a branch*, ветку **main** и папку **/ (root)**, нажмите **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://ЛОГИН.github.io/fin-analysis/`.

После любых изменений достаточно сделать коммит и `git push` — сайт обновится сам.
